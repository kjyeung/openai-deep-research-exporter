# openai-deep-research-exporter
This is a script to help convert OpenAI Deep Research conversations to markdown files.

## How to use
1. Use [ChatGPT-Exporter](https://github.com/pionxzh/chatgpt-exporter) to export the deep research conversation in both json and md format.
2. Run update_links.py to extract the links in the json file and incorporate them into the md file.
3. Enjoy.
